# Workflows

## 1. Discovery
Search target market broadly → normalize candidate identity → dedupe → collect minimum evidence → pass promising candidates to Investigator.

Minimum discovery evidence: active business signal + public web/social presence + plausible service/product.

## 2. Qualification
Verify activity → inspect website/social/funnel → identify concrete problem → identify commercial consequence → assess solution fit and ability to pay → score → reject weak leads.

## 3. Audit
Capture concise observations with URLs/context. Test mobile manually where possible. Measure technical metrics only with an actual measurement tool. Never invent speed/SEO scores.

## 4. Offer selection
For each A/B lead choose exactly one primary offer. Use the chain `Problem → Solution → Business value`. Secondary services may be stored but must not dilute the primary pitch.

## 5. Demonstration
Create the smallest artifact capable of making the value tangible: one mobile screen, one landing page, one chatbot flow or one automation diagram. Demo effort must be proportional to lead score.

## 6. Outreach preparation
Draft message from verified observations. Include one specific hook, one meaningful opportunity, one low-friction next step. Mark `READY` only when evidence is strong. Human approval is mandatory before sending.

## 7. Follow-up
Follow the configured cadence only after an actual outreach event. Respect opt-outs and `DO_NOT_CONTACT`. Every follow-up must add context/value rather than repeat the same pitch.

## 8. Outcome capture
Record response, meeting, proposal and revenue outcomes as events. Do not infer outcomes from silence.

## 9. Learning loop
Aggregate by niche, offer, score band, hook and channel. Identify what converts. Adjust discovery queries, qualification thresholds and offers based on actual outcomes.

## 10. Daily run
1. Read OS and current pipeline.
2. Search new candidates.
3. Deduplicate.
4. Investigate best candidates.
5. Score.
6. Produce top opportunities.
7. Update evidence/activity.
8. Flag human actions.
9. Publish a concise run summary.
